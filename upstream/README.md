# Vendored shadcn/ui source

Style `new-york-v4`, downloaded from https://ui.shadcn.com/r/styles/new-york-v4 by the `fetch-upstream` .NET command.

These files are **not compiled and not shipped**. They exist so the parity tests compare
against real upstream source rather than against a class string someone retyped, and so a
version bump is reviewable as a diff. MIT, © shadcn.
